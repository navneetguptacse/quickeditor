QuickEditor Workflow Guide

  • Shortcuts: Press Ctrl + Enter to run the active test cases. Run stress testing with Ctrl + Alt + S.
  • Dual Fuzzing: Place your optimal solution in Solution.cpp and a simple naive implementation in BruteForce.cpp. QuickEditor will run randomized inputs until it isolates the minimal counterexample.
  • Contest Templates: Use fast I/O speedups with cin.tie(NULL); ios_base::sync_with_stdio(false);.

Frequently Asked Questions

QuickEditor • Competitive Coding AI

How does automated stress-testing work?

QuickEditor runs your fast $O(N \log N)$ algorithm against a simple, obviously correct $O(N^2)$ brute-force algorithm on thousands of small randomized test cases. If their outputs differ, QuickEditor isolates the minimal failing input so you can debug in seconds.

Is QuickEditor permitted during live contests?

Rules vary by platform. On Codeforces and AtCoder, offline tools, testcase runners, and stress-testers are standard practice. For live AI assistance features, please review the specific contest's AI policy before participating in rated rounds.

Does my code get sent to third-party servers?

No. QuickEditor is engineered with zero code telemetry. Execution is handled locally on your machine or inside isolated client WebAssembly.

What languages are supported?

C++20 (GCC/Clang), Python 3.12, Java 21, Rust 1.75, and Go, with full template injection and fast I/O optimizations.
